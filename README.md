# getworksheet-files

Public worksheet PDFs and page-one previews for https://getworksheet.co, served by GitHub Pages.
Layout: worksheets/<collection>/<sheet>.pdf and <sheet>-{600,900,1200}.webp; collections/<id>-{600,900,1200}.webp for covers.
All files are free printables for home and classroom use; see https://getworksheet.co/license.
